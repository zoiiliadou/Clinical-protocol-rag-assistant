# Data Folder

This folder is used for local project data.

The protocol PDF is not included in this repository due to file size and licensing considerations.

To run the project locally, download the public protocol PDF:

https://www.nejm.org/doi/suppl/10.1056/NEJMoa2034577/suppl_file/nejmoa2034577_protocol.pdf

Then place it at:

```text
data/raw/C4591001_protocol.pdf
```

The generated vector store and audit database are also kept locally and are not included in the repository.
